How to run sunny.c

visit JSLinux

This you do via

JSLinux

type vflogin tinyC

enter tiny-C for pswd

launch the program by typing at the prompt

./sunny

This program will ask you a series of questions. Experiment.

Example 1 - a tiny world - enter width of 20 height of 15. Make it go
slow by saying 3000 to the pause question. Let it go for 50 generations.
Lastly you need to supply a "seed" number. How 'bout 813? <3

Kill the program by hitting Ctrl-C

Example 2 - a huge, speedy life - use a 60x80 board, a pause value of
100. Allow 1000 generations. Plant the 813 seed.
