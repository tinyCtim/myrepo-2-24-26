Consider the function y = x^2

Now consider the lines drawn between the first point and the 2nd point.

1,1 -> 3,3^2          slope = 4   because (9-1)/(3-1) = 8/2 = 4

1,1 -> 2,2^2          slope = 3   because (4-1)/(2-1) = 3/1 = 3

1,1 -> 1.5,(1.5)^2    slope = 2.5 because ((1.5)^2-1)/(1.5-1) = 1.25/.5 = 2.5

1,1 -> 1+h,(1+h)^2    slope = ((1+h)^2-1)/h = 2+h (proof omitted)

As h approaches 0, the slope, which is 2+h, approaches 2.

In this example, the points are on a curve which is called a parabola.

Visual interpretation: the lines approach a line that is tangent to the
curve at the initial point.
