Conway

Conway's Game of Life is a zero-player cellular automaton played on a
two-dimensional grid of square cells, where each cell is either alive or
dead and evolves based on its eight surrounding neighbors.

The Four Core Rules

Every cell interacts with its horizontal, vertical, and diagonal
neighbors. All changes happen simultaneously in discrete steps called
generations:

• Underpopulation: Any live cell with fewer than two live neighbors dies (as if by isolation).
• Survival: Any live cell with two or three live neighbors lives on to the next generation.
• Overpopulation: Any live cell with more than three live neighbors dies (as if by overcrowding).
• Reproduction / Rebirth: Any dead cell with exactly three live neighbors becomes a live cell.

How the Game Works

You set up an initial configuration of live cells (the "seed"), and then
the game runs automatically according to the rules above. You can
explore and test patterns yourself using the interactive Conway's Game
of Life Simulator.
